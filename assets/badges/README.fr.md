# Images locales des badges (solution de repli facultative)

[![Français](https://img.shields.io/badge/Langue-Français-3fe0a0?style=for-the-badge)](README.fr.md)
[![English](https://img.shields.io/badge/Language-English-2b9dff?style=for-the-badge)](README.md)

Le site charge les illustrations officielles depuis `https://assets.tryhackme.com/img/badges/<img>` grâce au champ `img` de `data/badges.js`. Un fichier placé ici et nommé `<slug>.png` n'est utilisé que si l'image du CDN ne se charge pas. Les badges sans fichier connu sur le CDN affichent leurs initiales jusqu'à ce que leur `img` soit trouvé. Badges qui n'ont actuellement aucun fichier connu sur le CDN :

mac-sleuth, filesystem-sleuth, memory-sleuth, linux-sleuth, windows-sleuth, malbuster, flow-hunter, apt-x-hunter, m365-sentry, domain-guardian, tooling-specialist, soc-level-up, league-locked-legend, study-group, best-friends-forever, trytrailme, alpha, beta, monthly-hacker, 1750-day-streak, 2000-day-streak

Les illustrations appartiennent à TryHackMe ; elles seront retirées sur demande.
