# Local badge images (optional fallback)

The site loads official artwork from `https://assets.tryhackme.com/img/badges/<img>` using the `img` field in `data/badges.js`. A file here named `<slug>.png` is used only when that CDN image is missing or fails. Badges that currently have no known CDN file:

mac-sleuth, filesystem-sleuth, memory-sleuth, linux-sleuth, windows-sleuth, malbuster, flow-hunter, apt-x-hunter, m365-sentry, domain-guardian, tooling-specialist, soc-level-up, league-locked-legend, study-group, best-friends-forever, trytrailme, alpha, beta, monthly-hacker

Artwork belongs to TryHackMe; remove on request.
