How badges work

Three ways a room badge is awarded

  1. Single room. Finish every task and the badge appears on your profile within minutes. Example: Blue, OhSINT, Hammer.
  2. Module badge. The badge is attached to the last room of a module, but it checks that the whole module is done. Finish the earlier rooms first or the final room won't trigger it. Example: Networking Nerd, Metasploitable, Packet Master.
  3. Series badge. Enrol from Learn, then Practice, then Series and complete every room inside the series page. Example: WindCorp, Overpassed, Pentester Tools.

Old room, new room

When TryHackMe refreshes a room, the badge usually moves to the new version. OWASP Top 10 and Hash Cracker are the classic traps — the room page may still show the badge art while the trigger lives elsewhere. Cards on this site list the current trigger first.

Didn't get it?

  • Open the room and confirm it shows 100% complete, including tasks with no questions.
  • For module and series badges, open the module page and confirm every room is ticked.
  • Refresh your profile after a few minutes; badges aren't always instant.
  • Still missing? Ask TryHackMe support to re-sync your room completions.

Suggested order

If you want badges fast, this is the order most people find efficient. It's an opinion, not an official path.

  1. Fundamentals first: cat linux.txt, Networking Nerd, Webbed, World Wide Web — they're part of the Pre Security path anyway.
  2. Quick wins: Blue, Ice, OhSINT, Pentesting Principles, Security Awareness.
  3. Web track: OWASP Top 10, Intro to Web Hacking, Burp'ed, Sword Apprentice, System Sniffer, Client-Side Champ, SQL Slayer, Authentication Striker, HTTP Smuggler.
  4. Defensive track: Wireshark, Packet Master, Logging Legend, Phishing, then the SOC rooms and the five Sleuth badges.
  5. Offensive track: Linux PrivEsc, Windows Priv Esc, Metasploitable, Hash Cracker, then Wreath, HoloLive and ADversary.
  6. Seasonal: Advent of Cyber runs every December and is the easiest high-value badge of the year.

Found a mistake? New badge?

Rooms get renamed and retired, and TryHackMe ships new badges without a changelog. The fastest way to fix this page is to open an issue with the badge name and the room link, or edit data/badges.js and send a pull request. Entries marked needs verification are the ones we'd love confirmed first.
